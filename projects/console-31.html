Project 31: De Weblog

Introductie tot ASP.NET Core MVC en Web Apps.

🎯 De Opdracht (15)

Situatie

"Weblog" is een log bijhouden op het web, maar iemand gooide er vroeger per ongeluk een spatie in en toen stond er "we blog". Op zijn Engels betekent dat "wij bloggen" en sindsdien is bloggen een werkwoord geworden. En zo zijn ook de woorden blog en blogger ontstaan zoals we dat vandaag de dag kennen.

Doelstelling

  • Ontwikkel een blog bestaande uit 1 pagina.
  • Op deze pagina kan je 3 verhalen lezen.
  • (1 punt)

Optioneel

  • Op deze pagina kan je verhalen posten. (+3 punten)
  • Maak gebruik van het MVC pattern. (+2 punten)
  • Maak gebruik van C#. (+3 punten)

📘 Extra Uitleg: Wat is MVC?

MVC staat voor Model View Controller. Het is het populairste design pattern voor webapplicaties in C# (ASP.NET Core).

  • Model (De Data): Dit zijn je classes. Bijvoorbeeld BlogPost.cs met een titel en inhoud. Hier zit geen logica of HTML in, alleen data.
  • View (Het Uiterlijk): Dit is de HTML pagina (vaak .cshtml in C#). De View 'krijgt' het Model en toont de data aan de gebruiker.
  • Controller (De Baas): De Controller ontvangt het verzoek van de browser (bv. "gebruiker klikt op /blog"), haalt de data op uit een database (of lijst), stopt het in een Model en stuurt het naar de View.

Stappenplan voor C# (ASP.NET Core):

  1. Maak een nieuw MVC project: dotnet new mvc -o MijnBlog
  2. Maak een class BlogPost (Title, Content, Author).
  3. In de HomeController, maak een lijst met 3 dummy Posts.
  4. Stuur die lijst naar de View: return View(posts);
  5. In Index.cshtml, gerbuik een foreach loop om ze in HTML te tonen.

🎯 Code Voorbeeld (Controller & Model)

// 1. Het Model (BlogPost.cs)
public class BlogPost 
{
    public string Title { get; set; }
    public string Content { get; set; }
}

// 2. De Controller (HomeController.cs)
public class HomeController : Controller 
{
    public IActionResult Index() 
    {
        // Maak dummy data (de "3 verhalen")
        var posts = new List {
            new BlogPost { Title = "Mijn Eerste Post", Content = "Hallo Wereld!" },
            new BlogPost { Title = "C# is cool", Content = "MVC maakt alles makkelijker." },
            new BlogPost { Title = "Vakantie", Content = "Ik ben naar Spanje geweest." }
        };

        // Stuur de lijst naar de View
        return View(posts);
    }
}
