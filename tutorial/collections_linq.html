C# Collections & LINQ

Arrays zijn leuk, maar in het echt gebruik je Lists en LINQ. Dit is de "Pro" manier.

1. List<T> (De Flexibele Array)

Een Array heeft een vaste grootte. Een List groeit automatisch mee. Bijna altijd gebruik je een List in plaats van een Array. 

using System.Collections.Generic; // Vergeet deze niet!

// Maken
List<string> boodschappen = new List<string>();

// Toevoegen
boodschappen.Add("Melk");
boodschappen.Add("Brood");

// Tellen
Console.WriteLine(boodschappen.Count); // 2

// Verwijderen
boodschappen.Remove("Melk");

2. Dictionary<K, V> (Sleutel & Waarde)

Soms wil je iets opzoeken, zoals een telefoonboek (Naam -> Nummer). Een Dictionary koppelt een unieke Key aan een Value. 

Dictionary<string, int> leeftijden = new Dictionary<string, int>();

// Toevoegen
leeftijden.Add("Ali", 20);
leeftijden.Add("Eva", 25);

// Opzoeken (Razendsnel!)
Console.WriteLine(leeftijden["Eva"]); // 25

3. LINQ (Superkrachten voor Data)

LINQ (Language Integrated Query) laat je filteren en sorteren in één regel code. Stop met het schrijven van `foreach` loops voor zoekwerk! 

using System.Linq; // CRUCIAAL!

List<int> cijfers = new List<int> { 5, 8, 1, 9, 3, 10 };

// 1. Where (Filteren)
// Pak alle cijfers hoger dan 5
var hogeCijfers = cijfers.Where(c => c > 5).ToList(); 
// Resultaat: 8, 9, 10

// 2. OrderBy (Sorteren)
var gesorteerd = cijfers.OrderBy(c => c).ToList();
// Resultaat: 1, 3, 5, 8, 9, 10

// 3. First / Any (Checken)
int eerste = cijfers.First(); // 5
bool isErEenTien = cijfers.Any(c => c == 10); // true
🚀 Lambda Expressies ( => )

Zie je dat pijltje c => c > 5? Dat heet een Lambda. Het betekent: "Voor elk cijfer 'c', check of 'c' groter is dan 5".

🎯 Oefening: De LINQ Meester

Je hebt een lijst met prijzen: `10.50, 5.00, 20.00, 3.50`. Gebruik LINQ om:
1. Alles onder de 10 euro te vinden.
2. Ze te sorteren van laag naar hoog.

Toon Antwoord 
List<double> prijzen = new List<double> { 10.50, 5.00, 20.00, 3.50 };

var goedkoop = prijzen
    .Where(p => p < 10.00)
    .OrderBy(p => p)
    .ToList();

// Resultaat: 3.50, 5.00
